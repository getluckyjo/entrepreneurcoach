# SEO — entrepreneurcoach.co.za

Single source of truth for the pre-launch SEO pass. Edit this file when keywords, titles, or schema change.

> **Stack note:** This site is **Astro 5**, not Next.js. Page metadata lives in `src/components/layout/BaseLayout.astro` props (not `generateMetadata`). OG images are generated by `src/pages/og/[slug].svg.ts` (not `opengraph-image.tsx`). The sitemap is the `@astrojs/sitemap` integration in `astro.config.mjs`. `robots.txt` is dynamic at `src/pages/robots.txt.ts`. Production domain is set in `astro.config.mjs` `site` and `src/data/site.ts` `domain`.

## Production domain

`https://www.entrepreneurcoach.co.za` — confirmed in `astro.config.mjs`. The apex (`entrepreneurcoach.co.za`) 301-redirects to www via `vercel.json`. Once cutover happens, `entrepreneurcoach.vercel.app` should be redirected too — see launch checklist.

## Schema deployed

Defined in `src/lib/seo.ts` and composed per page:

| Schema | Where | Notes |
|---|---|---|
| `WebSite` | Home | `@id` for knowledge-graph linking |
| `Person` | Home, About | jobTitle: Entrepreneur Coach, knowsAbout list, sameAs (LinkedIn + ventures), alumniOf Cambridge Judge |
| `ProfessionalService` (LocalBusiness) | Home | NAP (Ideas Cartel, Claremont, Cape Town), geo, areaServed (ZA + US + UK + EU), opening hours Mon–Thu 09:00–17:00, priceRange R2,500–R45,000 |
| `Service` (one per package) | Home, /coaching | Six Service nodes — name, description, provider, areaServed, audience, Offer with priceCurrency ZAR, eligibleDuration |
| `FAQPage` | /coaching | 7 questions auto-generated from `site.ts` `faqs` array |
| `Article` | /journal/[slug] | headline, description, datePublished, dateModified, articleSection (category), author, publisher, mainEntityOfPage |
| `BreadcrumbList` | All non-home | Home → page (and Home → Journal → post for posts) |

`VideoObject` is reserved for when talk recordings ship — wire when a recording exists.

## OG images

- Endpoint: `src/pages/og/[slug].svg.ts` enumerates one OG per known panel from `src/lib/og.ts`.

## Performance

- LCP: portrait `loading="eager" fetchpriority="high"` on home + about.
- Geist (variable) ships `font-display: swap` from `@fontsource-variable/geist`. Caveat loaded with `display=swap`.
- Marquee strip is text in the DOM (not an image).
- `vercel.json` adds HSTS, X-Content-Type-Options, Referrer-Policy, and immutable cache for `/og/*`.

## Analytics

- `PUBLIC_GA4_ID` and `PUBLIC_PLAUSIBLE_DOMAIN` are wired conditionally in `BaseLayout.astro`. Setting either env var loads the relevant snippet. Plausible is the recommended default — privacy-friendly, GDPR-clean, matches the existing essential-cookies stance.
- `PUBLIC_GSC_VERIFICATION` and `PUBLIC_BING_VERIFICATION` are wired as meta tags. Set them in Vercel env vars before launch.
